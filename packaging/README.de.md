# AnnoOrganizer für Windows x64

[English](README.md) · [Deutsch](README.de.md)

Das ganze ZIP entpacken und **AnnoOrganizer.exe** öffnen. `_internal/` muss neben der EXE bleiben. Keine Python-Installation, kein Installer, kein pip zur Laufzeit und keine Administratorrechte erforderlich. Anno 117 und 1800 benötigen weiterhin ihre installierten Spielressourcen; die Anno-1404-Demo braucht keine Spielinstallation.

Spiel wählen, **Mitgelieferte Demo** aktiviert lassen und **Erzeugen** drücken. Eigene Eingaben lassen sich später über Dateiauswahl oder Konfigurationsimport einrichten. Spielstände und Stempel werden nur gelesen. Einstellungen und Ausgaben liegen standardmässig unter Windows-LocalAppData und bleiben beim Austausch des Programmordners erhalten. Erzeugen überschreibt keine persönliche Einstellungsdatei.

Bei deutscher Windows-Anzeigesprache startet die Oberfläche auf Deutsch, sonst auf Englisch. Eine gespeicherte DE/EN-Auswahl hat Vorrang. Galerien nach einem erfolgreichen Lauf öffnen; Fehler stehen unter **Protokolle**. Ein Abbruch wartet auf die nächste sichere Grenze.

Dieses Entwicklungspaket ist nicht signiert. Windows kann eine SmartScreen-Reputationswarnung anzeigen. Herkunft und veröffentlichte SHA-256-Prüfsumme prüfen; Signierung wird separat bewertet. Es werden keine automatischen Updates installiert.
