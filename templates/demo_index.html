ANNO - Organizer für Windows

Erstelle deine eigenen Karten- und Stempelgalerien mit der deutschen oder englischen Oberfläche. Das portable Paket enthält alles Nötige – keine Python-Installation erforderlich.

Windows-Paket herunterladen (ZIP)Version v0.1.22 · Details und Prüfsummen

Für Windows 10/11 (64 Bit). ZIP vollständig entpacken und AnnoOrganizer.exe starten. Beim ersten Start werden erkannte Spiele und Standardordner vorgeschlagen.

Spielstände und Stempel werden ausschliesslich gelesen. Deine Originaldateien bleiben erhalten.

Bebilderte Anleitung für den Organizer

Das Programm ist nicht digital signiert. Windows kann deshalb einen Sicherheitshinweis anzeigen.

ANNO - Save Manager für Windows

Kopiere oder verschiebe einzelne Saves, benenne ganze Profilordner um und ändere Prätor-/Spielernamen in einzelnen oder allen Saves eines Ordners – für Anno 117 und Anno 1800.

Save Manager herunterladen (ZIP)Version v0.1.22 · Details und Prüfsummen

Für Windows 10/11 (64 Bit). ZIP vollständig entpacken und AnnoSaveManager.exe starten. Python wird nicht benötigt; die DE/EN-Sprachwahl wird gespeichert.

Vor Änderungen werden geprüfte ZIP-Sicherungen erstellt. Eine Bearbeitung bei laufendem Spiel wird gesperrt.
